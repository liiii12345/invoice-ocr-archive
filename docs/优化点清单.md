## 建议的节奏

1. 先挑 **1、2、4** —— 这三条解决的是「本机真用起来」的堵点（数据集要改代码、llm 没入口、策略选哪个靠猜）。

3. 底层 19、20 是简历上最值钱的一条（把「能抽」变成「抽得对」），但工作量大，可以跟上面并行推。
4. 界面花活（5、7、8、10、13 里的轻量项）最后做，不影响正确性。
